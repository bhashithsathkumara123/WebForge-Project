# LifeLink Blood

## Overview

LifeLink Blood is a web-based blood donation and blood stock management system that connects **patients**, **donors** and **hospitals** in one platform. It helps patients find compatible blood quickly, lets donors see where their blood type is needed most, and gives hospitals a simple way to manage their stock and respond to requests.


## Key Features

**Patients**
- Search hospitals for a required blood type, including compatible alternatives (for example, O- for an A- patient)
- Send a formal blood request with the number of units, urgency level and a note
- Track the status of each request (Pending, Approved, Rejected)

**Donors**
- See low-stock alerts for the blood types they can donate to
- Pledge a donation date at a chosen hospital
- View pledge status and donation history
- Automatic 4-month gap enforced between donations

**Hospitals**
- Manage blood stock for all eight blood types
- Approve or reject patient requests, with stock deducted automatically on approval
- Confirm or decline donor pledges, with stock increased automatically on confirmation

**Everyone**
- The home page shows total blood available across all hospitals
- Stock is labelled OK, LOW (below 10 units) or CRITICAL (below 5 units), and alerts appear on the home page

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP (PDO)
- **Database:** MySQL
- **Server environment:** XAMPP (Apache + MySQL)
